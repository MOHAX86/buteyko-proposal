Удаление данных пользователя приложения «Интервальная ВЛГД»

Удаление пользовательских данных

Пользователь приложения «Интервальная ВЛГД» может запросить удаление данных, связанных с использованием приложения.

Для этого отправьте запрос на: mag0953688186@gmail.com
В теме письма укажите: «Удаление данных — Интервальная ВЛГД».

В запросе укажите сведения, позволяющие идентифицировать данные, которые необходимо удалить.

После получения запроса разработчик удалит данные, находящиеся под его контролем, если их хранение не требуется по закону.

Данные, которые хранятся только локально на устройстве пользователя, можно удалить также путём очистки данных приложения или удаления приложения с устройства.

Если какие-либо данные необходимо сохранить по юридическим или техническим причинам, пользователь будет уведомлён об этом.

Видалення даних користувача

Користувач застосунку «Інтервальна ВЛГД» може подати запит на видалення даних, пов’язаних із використанням застосунку.

Щоб подати запит, надішліть лист на:

mag0953688186@gmail.com

У темі листа вкажіть:

«Видалення даних — Інтервальна ВЛГД»

У запиті вкажіть інформацію, яка допоможе ідентифікувати дані, які потрібно видалити.

Після отримання запиту розробник видалить дані, що перебувають під його контролем, якщо їх подальше зберігання не вимагається законодавством або іншими обов’язковими вимогами.

Дані, які зберігаються лише локально на пристрої користувача, також можна видалити шляхом:

  • очищення даних застосунку в налаштуваннях Android;
  • видалення окремих записів у застосунку, якщо така функція доступна;
  • видалення застосунку з пристрою.

Якщо певні дані необхідно зберегти з юридичних або технічних причин, користувач буде поінформований про це.

User Data Deletion

Users of the “Interval VLHD” application may request deletion of data associated with their use of the application.

To submit a deletion request, send an email to:

mag0953688186@gmail.com

Use the following subject line:

“Data Deletion — Interval VLHD”

Please include information that will help identify the data you would like to have deleted.

After receiving the request, the developer will delete data under their control unless continued retention is required by law or other mandatory requirements.

Data stored only locally on the user’s device can also be deleted by:

  • clearing the application data in Android settings;
  • deleting individual records within the application, where such functionality is available;
  • uninstalling the application from the device.

If certain data must be retained for legal or technical reasons, the user will be informed accordingly.
